# PackBack

Pack a list, then check those same items before you leave.

Package: `com.PackBackMNG.PackBack`

Remote config: [N314.json](https://api2.blwsmartware.net/N314.json) — `disable=1` hides Google Play Billing popups only. Shop stays open for coin unlocks.

| Product | Type |
| --- | --- |
| `pb_pack_1` … `pb_pack_10` | Consumable coins |
| `pb_remove_ads` | Non-consumable |
| `pb_pro` | Non-consumable, more than 8 trips |

PackBack does not detect real objects. Bring back only lists items you marked as packed.
